# Working in this project

A FastAPI backend generated by fastro. `backend/` holds everything that runs.

## The layers

- `src/interfaces/`: the app itself, the FastAPI factory and the routers it mounts.
- `src/modules/<name>/`: one domain each, as `models.py`, `schemas.py`, `crud.py`, `service.py`
  and `routes.py`. A module owns its tables and its rules, and reaches another module through
  its service rather than its tables.
- `src/infrastructure/`: what every module uses, such as the settings and the database, plus
  whatever each selected feature brought with it.
- `src/wiring/`: generated. It lists what this project selected, so the app imports one name per
  extension point instead of asking what exists.

## Adding code

Add a domain as a module under `src/modules/`, following an existing one: the names and the file
split are the pattern to copy. Register its router and anything else it contributes under
`[app].contributes` in `fastro.toml`, then run `fastro sync`.

**Never edit `src/wiring/`.** Those files are written from `blueprint.toml` and `fastro.toml`, and
`fastro sync` overwrites them. To change what is wired, change `[app]` in `fastro.toml` and sync.

A setting of your own goes on a settings class in the module that reads it, contributed under
`[app].contributes.settings` in `fastro.toml` and picked up by `fastro sync`. Add its variable to
`backend/.env.example` outside the marked sections, which belong to the features that own them.
The files under `src/infrastructure/config/` are the blueprint's: a change there is one
`fastro update` has to merge, so keep your own settings in your module.

## Before finishing

From `backend/`:

```bash
uv run --no-sync ruff check . && uv run --no-sync ruff format --check .
uv run --no-sync mypy src scripts migrations tests
uv run --no-sync pytest
```

Then `fastro check --json` from the project root, and read what it reports. A schema change needs a
migration: `uv run --no-sync alembic revision --autogenerate -m "what changed"`, reviewed by hand
before it is applied.
